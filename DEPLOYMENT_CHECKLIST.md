## 📋 Step-by-Step Deployment (5 minutes)

### Step 1: Open Command Prompt in Portfolio Folder
```
1. Press Windows Key + R
2. Type: cmd
3. Press Enter
4. Navigate to your portfolio folder:
   cd Downloads\port
```

### Step 2: Initialize Git (if not already done)
```
git init
git config user.email "mickymander2@gmail.com"
git config user.name "Taranpreet Singh Mander"
```

### Step 3: Add All Files
```
git add .
```

### Step 4: Commit Your Portfolio
```
git commit -m "Deploy portfolio: Personal Information Security Portfolio"
```

### Step 5: Create GitHub Repository
1. Go to https://github.com/new
2. Create repository named: **portfolio** (exactly this name)
3. Do NOT initialize with README, .gitignore, or license
4. Click "Create repository"
5. Copy the repository URL (something like: https://github.com/Taranpreetsingh077/portfolio.git)

### Step 6: Add Remote and Push
```
git remote add origin https://github.com/Taranpreetsingh077/portfolio.git
git branch -M main
git push -u origin main
```

### Step 7: Enable GitHub Pages
1. Go to your repository: https://github.com/Taranpreetsingh077/portfolio
2. Settings (top right) → Pages (left sidebar)
3. Under "Build and deployment", select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Click "Save"

### Step 8: Wait & Verify (2-3 minutes)
Your portfolio will be live at: **https://Taranpreetsingh077.github.io/portfolio**

You'll see a blue notification when it's ready!

## 🆘 Troubleshooting

**Portfolio not showing after 5 minutes?**
- Check that repository is public
- Go to Settings → Pages and verify it's set to `main` branch
- Wait up to 10 minutes (first deployment is slower)

**"Repository not found" error during push?**
- Check you created the repo: https://github.com/new
- Verify you changed the remote URL to your actual repo

**Links showing 404?**
- Make sure GitHub repositories are created and public
- Links reference `github.com/Taranpreetsingh077/{project-name}`
