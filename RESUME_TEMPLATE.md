## TIPS FOR YOUR RESUME

1. **Be Specific:** Use exact tool names, versions, and technologies
2. **Use Metrics:** "Identified 50+ vulnerabilities" is better than "Found vulnerabilities"
3. **Focus on Impact:** Show what problems you solved, not just what you did
4. **Keep It Real:** Don't exaggerate skills. Hiring managers will test you!
5. **Tailor for Jobs:** Adjust your resume based on job descriptions
6. **Use Keywords:** Include terms from job postings (ATS keywords)
7. **Action Verbs:** Start bullets with "Developed", "Implemented", "Designed", "Created"
8. **One Page:** For students, keep it to 1-2 pages maximum

## HOW TO CREATE A PDF RESUME

**From Google Docs:**
1. Write your resume in Google Docs
2. File → Download → PDF Document (.pdf)
3. Save as `resume.pdf`

**From Microsoft Word:**
1. Write your resume in Word
2. File → Save As → PDF
3. Save as `resume.pdf`

**From HTML/CSS:**
1. Create a styled HTML resume
2. Print to PDF (Ctrl+P → Save as PDF)
3. Save as `resume.pdf`

**Online Tools:**
- Canva (canva.com) - Design templates
- FlowCV (flowcv.io) - ATS-friendly resumes
- ResumeBuilder (resumebuilder.com)
